# Meadow prototype P2

An isolated continuation of P1, authorized by “Go ahead with the next recommended iteration.” Production source, assets, saved scene meanings, historical evidence and acceptance states are preserved.

Render revision 2 compares the current 72-stem canopy and retained P1 atlas with 12-, 18- and 24-stem volumes. These retain original F2 stem numbers, heights, curves, normals, root placement, geographic wind, logarithmic depth and strict overlap ranks. Wider ribbons are new experimental appearance. Logical packed populations are unchanged; visual acceptance is not inherited.

`submission-p2.js` installs a compiled winner and packet-range planner on one isolated lifecycle/backend instance. It preserves insertion/reference order and retains receipt validation, hashes, record uploads, per-record view tests, fenced banks, commit and retirement. Numeric backing is charged to the existing service. It still builds JS assignments/ranges; fully typed banks/admission and complete JS/worker ownership remain unfinished.

`capture-p2.js` prepares the actual requested perspective view or every panorama face at its actual internal resolution before encoding. A capacity conflict rejects the transaction without a file or completion event. Limits and antialiasing remain unchanged. This is an experimental API, not production promotion.

## Reproduce

```powershell
node analysis/meadow-prototype-p2/run-p2.cjs
```

Each execution creates a fresh attempt and freezes the experiment sources. It uses its own HTTP origin/browser, enters Explore → Watershed → Open meadow → Meadow study → Visit, and runs seven-view GPU/coverage comparisons, 1,800 ordered oracle poses, six 900-frame preparation replays, a separate sampled-movement recording, and actual 4K capture transactions. The direct-draw replay does not replace ordinary-app H1. Existing fixtures remain unchanged.

`last-run.json` identifies the owned runtime/evidence. Do not rerun `prepare.cjs` merely to review the result. Inherited P1 scripts are retained references; use `run-p2.cjs` for P2.
