The decision

Stop this optimization line. The next useful experiment is a replacement coverage pipeline that retains canonical geographic cells independently of the whole-view reference transaction and updates only affected cells during motion.

The existing root, density, support, exclusion, wind, strict rank and resource limits remain part of that experiment. Establish uninterrupted walking and turning first, then choose a shipping budget from complete frame measurements.

The shared-storage branch passed record-byte comparisons but failed native GPU reference ownership during moving use. It is excluded from the final budget comparison. Return-to-start warm-up failures and prior insufficient view proofs are preserved.
