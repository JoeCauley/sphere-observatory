rectangle. All accepted children stay with their root, including support across
storage edges; per-region spheres include packed origins plus the botanical/wind
envelope. Exclusions, density, prototype fields and geographic wind are retained.

parent path. Sizes 1/2/4/8 m are supported, with a job covering one block or a
two-by-two bundle, bounded inside one parent. Offsets align to job size.

## Generation and ownership

The shared blade/clump generators accept streaming sinks. Production compact
workers do not retain complete arrays of source plant/root objects. They pack
each transient instance directly into bounded 32-byte staging, retain a two-byte
region/prototype tag, then gather into one exact output allocation. Staging and
output coexist while gathering/hashing and are both reported. This is bounded
job gathering, not full-frame population repacking.

The original FNV sampler has an exact two-word implementation for compact jobs;
2000 seed/stream/counter/Unicode cases and actual parent records match the original
BigInt values. The shared geography placement query uses the same canonical
direction, exclusions and wetness without unused feature/representation metadata.
Old appearance and legacy worker paths retain their existing routing.

Workers cache only parent area summaries, not support nodes or plant objects.
Each immutable configuration has at most 16 summaries and an explicit 8192-byte
worker cache allowance. Content changes clear the cache. Original area nodes
exist only during measurement. One-job scratch credits cover staging/tags, up to
17 by 17 transient area nodes, a fixed transient object allowance and hash scratch.
These are bounded ownership allowances, not complete empirical object attribution.

Configuration is sent once per worker/content lifetime. Preparing cancellation
keeps credit until result discard or producer termination. Queued work is bounded
and prioritised: foreground, imminent travel, overlap, then peripheral guard.
`admitRequests` limits outstanding producers and reprioritises live queued demand;
denied admission never dispatches a producer.

CPU compaction moves logical allocation addresses only, with no record copy.
Each step has explicit record/byte limits, pins queued/preparing jobs and changes
slot generations. Consumers replace returned handles; old references fail.
It is forbidden when a GPU backend is attached. HR-03/HR-04 must implement
physical relocation, allocated capacity and safe GPU last-use ownership.
