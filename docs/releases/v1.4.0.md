# Observatory v1.4.0

This release brings the public v0.9 build up to the current Observatory, collecting the geography, local exploration and renderer work developed through v1.4.

![A wide view from the polar station](../../examples/v1.4/polar-station.png)

*From the polar station. See the [six new in-engine views and their scene files](../../examples/v1.4/) for Wound edges, Shade structures, clouds, walking and exterior wreckage.*

## What is included

- An adjustable habitat waist, three aligned Shade tracks, supporting machinery fields and two polar entry facilities.
- Ten walkable biome samples, two entry courts, and Wound, Shade and exterior inspection destinations.
- Continuous local Wound and Shade structures with streamed detail, richer surface materials and local shadows.
- Solid-surface flight collision, travel through real openings, surface level lock and a camera that follows the inspected Shade through simulation time.
- Volumetric local clouds, bounded atmospheric haze and dimensional exterior wreckage.
- Corrected Wound air integration and selective subpixel sampling along analytic Shade silhouettes and fractures.
- Independent Shade material footprints at mixed-object pixels, a stable distant finish and filtered procedural district boundaries. See [material sampling details](../Observatory-Shade-Filtering-14.md).
- Ten unique biome-specific Wound-edge textures, a continuous 240 km damage transition and matching upper-wall deposits.
- Fullscreen flight controls and browser-local settings restoration. Reopening restores the scene paused. Space remains play/pause in flight and jump on foot.
- Local photographs, panoramas and portable scene files. Still captures prime their final-resolution render before encoding.

## Run the release

Download and extract **sphere-observatory-1.4.0.zip**, then enter the `sphere-observatory-1.4.0` folder. With Node.js 20 or later:

```sh
npm start
```

Open **http://127.0.0.1:8766/**. There is no build step or runtime package installation. The included Windows launcher also starts a managed local server. Hardware-accelerated WebGL 2 is required; see the [README](../../README.md) for setup and stopping the server.

If an older copy is using port 8766, stop that server before starting the extracted release, or use `node serve.cjs 8767` and open the corresponding address. Browser settings belong to that browser and origin; use exported scenes to transfer a view between addresses.

Before the first refresh from a version without automatic persistence, export the current scene if it should survive. New settings then save automatically in the same browser and origin. No account, API key, runtime AI or external service is required.

## Validation and practical limits

The CPU suite, 505,728 close-boundary classification rays, moving Shade attachment, fullscreen controls, atmospheric integration, Shade silhouette reference comparisons, ten Wound material loads and browser-session restoration were checked during development. The Wound material comparison covers 13,824 GPU probes; the actual 4K photograph ZIP path produced identical repeated PNGs after priming. Detailed results and measured costs are in the [v1.4 notes](../Observatory-Polish-14.md).

The source bundle includes deterministic capture fixtures; generated local review galleries and browser profiles are excluded. `npm test` needs only Node. Browser validation additionally needs Playwright and a hardware-capable browser; it is a development dependency, not an application requirement.

This remains a visualization prototype. Gravity, shell support, atmospheric containment and Shade propulsion are explicit assumptions. Local walking samples are not complete game levels. Warm preview timings do not include shader startup or uncached geometry construction, and exact capture byte identity across different GPUs is not claimed.

An intermittent first-use 4K export mismatch remains documented in the v1.4 notes. The instrumented rerun matched exactly; failed capture checks now preserve images and metadata for diagnosis.

Original authored texture assets and their prompts are included. Star Agent informed technique research; no code or content was copied from it.

## What comes next

The [next development plan](../Observatory-Next-Leap.md) proposes corrected Wound arrivals, smoother geometry streaming, an engineering-informed shell atlas, cloud shadows and a Fallen Shade landmark. These are future work. Blender imports and full game levels remain feasibility proposals.
