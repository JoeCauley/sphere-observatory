# Hero albedo maps

Created with the built-in OpenAI image-generation tool, 2026-09-09. Prompts requested 2048-square images; actual delivered assets are 1254 × 1254. The renderer preserves that native resolution, rather than wasting memory on upscaling. Each contains about six times as many source pixels as the previous 512-square runtime local layer. These are approximate albedo artworks, not height surveys. No runtime AI.

## Prompt set

Subject: near-black fir and oak canopy, ancient tangled woods, mossy grey stone clearings, thin muted brown forgotten paths, pine green. Create ONE single square 2048x2048 richly detailed map covering an 8 km wide continuous landscape. Full-frame true orthographic straight-down aerial material photograph. One coherent irregular landscape with broad nonperiodic variation, lots of small varied features, no central focal point. Organic transitions and asymmetric landforms across entire image; no obvious regular lattice, repeated motifs, mirror symmetry, tile borders or panels. This is NOT a triptych. Fine details should remain readable at low altitude. Physically plausible muted diffuse surface reflectance and even overcast lighting, no directional baked shadows, sky, haze, clouds, perspective, horizon, text, frame or labels. Rich variation within this biome's colour family, useful broad shape without dramatic contrast that would reveal repeated sampling.
