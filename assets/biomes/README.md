# Biome texture sources

Generated with OpenAI image generation for this project on 2026-09-09. These are illustrative albedo maps, not geographic surveys. No image generation runs in the app.

Each PNG is 2172 × 724 pixels: three equal square panels for a 256 km region, 16 km district and 1 km local tile. Runtime resamples each panel to 512 × 512, builds isolated mip chains and uses mirrored repetition. This is a limited material LOD system on a smooth shell, not displaced 3D terrain. Fine maps share a biome and colour family but are not exact zooms of the coarse landforms.

## Generation prompts

The requested dimensions in the prompts were advisory; the delivered files use the dimensions above. All ten outputs were visually inspected. The Dark Age Forest prompt below reconstructs the shared generation brief; other prompts are recorded verbatim.
