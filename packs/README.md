# Observatory biome packs

Open **Explore → Biomes** in the running Observatory to install a place and visit it. The catalogue chooses the active version. Older directories support existing saves, earlier studies and direct comparisons.

| Offered pack | Version | Placement |
| --- | --- | --- |
| Infinite Meadow | 1.3.0 | A plot beneath a shade track |
| Infinite Industry | 1.4.1 | A plot in the open shell works |
| The Sideways City | 1.0.0 | A plot beneath a shade track |
| The Outfall | 1.0.0 | The northern Border of the installed Meadow |

The host and packs share the [biome contract](CONTRACT.md). The [project README](../README.md) includes the clone command, controls and screenshots. [Machine-readable catalogue](biome-library.json)
